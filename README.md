# Shine Pressure Wash

A responsive, build-free website for Shine Pressure Wash. It is ready to host directly with GitHub Pages.

## Preview locally

Open `index.html` directly in a browser. You can also use a local static-server extension such as VS Code Live Server if you want automatic refresh while editing.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.

The quote form uses `mailto:` to prepare an email to `robin@shinepw.ca`; the site does not collect or store submissions.
